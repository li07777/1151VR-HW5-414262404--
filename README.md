## 二、專案簡介與製作動機

本次作業使用 Unity 6 製作 3D 寶可夢收服遊戲，以可愛、療癒的拉拉熊風格為主題。遊戲中由拉拉熊擔任訓練家，泡沫栗鼠（Minccino）作為收服目標，並使用粉色精靈球與粉紅色粒子特效，營造溫馨的遊戲畫面。

透過本次實作，我練習了 3D 模型匯入、Terrain 地形編輯、草地與樹木配置、C# 角色控制、拋物線動畫、粒子系統、音效播放及 UI 互動。

## 三、遊戲內容與功能

- **3D 模型**：匯入拉拉熊訓練家、泡沫栗鼠與粉色精靈球模型，並調整位置、縮放及方向。
- **環境建置**：利用 Unity Terrain 製作草地、起伏山丘與樹木，搭配卡通風格的場景配置。
- **人物控制**：使用 WASD 控制拉拉熊移動，Shift 加速，移動時有手腳擺動效果。
- **精靈球拋擲**：按 Space 後，拉拉熊右手先蓄力揮動，再將精靈球沿拋物線拋向寶可夢。
- **收服特效**：精靈球抵達目標後產生粉紅色粒子，泡沫栗鼠逐漸縮小並消失。
- **音效**：包含拋球、收服和成功三種音效；收服音效播放完後進入成功階段。
- **UI 互動**：收服成功時顯示 Capture Success! 與 Retry 按鈕；可按 R 或 Retry 重新開始。
- **鏡頭控制**：相機平滑跟隨拉拉熊移動，拋球時暫停跟隨以利呈現動畫。

## 四、遊戲操作

| W / A / S / D | 移動拉拉熊 |

## 五、製作流程

### 1. 建立 Unity 3D 專案
使用 Unity Hub 建立 `PokemonCapture3D` 3D 專案，新增 MainScene，並整理 Models、Materials、Scripts、Prefabs、Effects、Audio 等資料夾。

### 2. 匯入並配置 3D 模型
透過 glTFast 匯入 GLB 模型，放置拉拉熊、泡沫栗鼠及粉色精靈球，調整 Transform、材質及大小，並將精靈球建立成 Prefab。

### 3. 建置自然場景
使用 Unity Terrain 的 Raise or Lower Terrain 繪製起伏山丘，透過 Paint Texture 加入草地紋理，再使用 Paint Trees 配置樹木；同時調整樹木 Shader 以解決材質變粉紅色的問題。

### 4. 設計拋球與角色動畫
建立 ThrowPoint 與 PokeballThrower C# 腳本，使用插值與拋物線公式控制精靈球飛行、旋轉；另外控制拉拉熊右手 `hand.r` 的旋轉，呈現蓄力、揮手、恢復的動作。

### 5. 製作收服效果與音效
利用 Particle System 製作粉紅色粒子特效，控制泡沫栗鼠縮小消失，播放拋球、收服及成功音效，並加入成功文字與重新開始按鈕。

### 6. 加入人物移動與鏡頭跟隨
使用新版 Input System 讀取 WASD、Shift、Space、R，加入角色手腳擺動和跟隨鏡頭，使遊戲具備更完整的操作體驗。

### 7. 測試與修正
測試模型顯示、Terrain 場景、角色移動、拋球動畫、音效完整播放、粒子特效、Retry 按鈕及重新開始功能。

## 八、學習心得

這次 HW5 我製作了以拉拉熊為訓練家、泡沫栗鼠為收服對象的 3D 寶可夢收服遊戲。相較於之前的 Unity 作業，這次需要結合 3D 模型、Terrain 地形、角色動畫、粒子特效及音效，整體製作過程更加完整，也讓我學到許多新的 Unity 功能。

在場景製作方面，我學會使用 Terrain 建立起伏的山丘，並加入草地材質及樹木，讓遊戲環境更加自然。一開始匯入樹木時，曾經遇到材質變成粉紅色的問題，後來透過調整 Shader 才成功顯示正常顏色。另外，我也嘗試使用 C# 控制拉拉熊的 WASD 移動、手腳擺動及右手拋球動畫，讓角色不再只是站在原地。

我覺得這次最有成就感的部分是精靈球收服系統。透過程式讓精靈球沿拋物線飛向泡沫栗鼠，命中後產生粉紅色粒子特效，並搭配音效及角色縮小消失的動畫，最後顯示收服成功的文字與重新開始按鈕。製作過程中也遇到輸入系統不相容、程式重複宣告及音效播放時間等問題，讓我練習如何透過 Console 找出錯誤並逐步修正。

透過這次作業，我不只更熟悉 Unity 的 3D 場景設計，也學會將不同的程式功能整合成一個可以實際操作的遊戲。雖然過程中花了不少時間調整，但看到拉拉熊能夠移動、揮手並成功收服寶可夢時，讓我很有成就感，也更了解遊戲開發需要不斷測試與修改才能完成。
